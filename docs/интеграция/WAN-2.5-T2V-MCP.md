# WAN 2.5 T2V Preview через owner MCP

Статус: начальный source-bound срез с одной сквозной проверкой 19 октября 2026.
Через MCP выполнен один generation POST и получен MP4 для сочетания
`720P` / `16:9` / 5 секунд / `prompt_extend:false` / `seed:null`.
Метаданные результата: H264, 1280×720, 5.041667 секунды, AAC. Остальные
сочетания и внутреннее исполнение провайдера этой проверкой не подтверждены.

## Включение

Группа owner stdio выключена по умолчанию. Для шаблона конфигурации используйте
отдельный opt-in:

```sh
node scripts/print-media-mcp-config.mjs --confirm-enable-paid-tools --include-wan25-t2v-preview
```

Опция включает только `SYNTX_OWNER_WAN25_T2V_PREVIEW=1`. Она не добавляет путь
к `ffprobe` или другой инструментальной переменной. Генератор печатает JSON,
не меняет настройки MCP-клиента, не читает credentials, не подключается к сети,
не загружает файлы и не запускает генерацию. Общий шаблон также содержит
существующие owner-группы; перед установкой проверьте его и оставьте только
нужные блоки.

Без `--confirm-enable-paid-tools` конфигурация не выводится. Флаг подтверждения
должен идти первым; параметры режима без него отклоняются.

## Начальный поддерживаемый срез

Единственный model ID — `wan_25_t2v_preview`, AI name — `wan_video`, scope —
`video`. Все параметры задаются явно, значения формы автоматически не
подставляются:

- разрешение: `480P`, `720P` или `1080P`;
- соотношение сторон: `16:9`, `9:16`, `1:1`, `4:3` или `3:4`;
- для `480P` допустимы только `16:9`, `9:16` и `1:1`;
- длительность: 5 или 10 секунд;
- `prompt_extend`: явное boolean-значение;
- `seed`: только `null` в этом начальном срезе.

Локальная граница prompt — 1 500 UTF-16 units. Это защитное ограничение
клиентского кода, а единицы и лимит провайдера не доказаны. Входного видео,
изображений и аудио нет: `file_urls` пустой массив. Поля `native_audio`,
`shot_type` и `audio_setting` в начальном wire не отправляются; отсутствие
этих полей не гарантирует беззвучное видео. В проверенном MP4 есть AAC-дорожка.

## Инструменты и результат

- `syntx_owner_generate_wan25_t2v_video` — одна явная попытка после проверки
  текущей связи, подписки, model access, свежей quote и баланса;
- `syntx_owner_get_wan25_t2v_result` — GET-only сверка после неизвестного
  ответа;
- `syntx_owner_list_wan25_t2v_recoveries` — список наблюдений текущего процесса.

В каталоге для quote указаны `resolution` и `video_duration`. Сравнение quote с
балансом — лишь проверка доступности на момент чтения, не жёсткий предел
списания. При неопределённом generation POST повторно вызывать генерацию
нельзя; используйте только result/recovery GET. Recoveries хранятся в памяти
процесса и пропадают после его перезапуска.

Закреплённый public catalog —
`sha256-1d8e35274b0e0c6198cc60ea58899c35b32bd94fd3ea28911c6b2be5747e30a0.json`;
параметры связаны с source build `1792363638`, формой SHA-256
`308d9504b372088774bc543f1527a2b4413d5c8db078e00755088065b735bd8a` и
`cost2.js` SHA-256 `3d9bb6b5fb2ee26c8cc61251777fa3bad121a7a5754150fdcfd2f7062bcbc8fa`.
Источник и локальные тесты сами по себе не подтверждают фактическое поведение
интерфейса, entitlement другого аккаунта, тарификацию или корректность списания.
Получение MP4 подтверждено отдельно только для указанного выше сочетания;
полное совпадение всех настроек с интерфейсом не заявляется.
