# WAN 2.5 I2V Preview через owner MCP

Это локальная opt-in интеграция для единственной модели `wan_25_i2v_preview`. Она подключается через owner stdio; по умолчанию группа выключена. Это отдельная preview-ветка, а не расширение WAN26/Flash и не доказательство приёма результата провайдером.

## Включение

Для owner-stdio нужен точный environment flag:

```text
SYNTX_OWNER_WAN25_I2V_PREVIEW=1
```

Unset, пустое значение и `0` оставляют группу выключенной; разрешено только `1`, прочие значения считаются ошибкой конфигурации.

Локальный генератор конфигурации:

```sh
node scripts/print-media-mcp-config.mjs --confirm-enable-paid-tools
```

Генератор печатает JSON и сам не меняет настройки клиента, не читает credentials и не обращается к сети. Подтверждённый шаблон также включает другие существующие owner-media flags: перед установкой проверьте вывод и удалите из него не нужные вам группы. Не публикуйте этот локальный конфиг.

## Доступные инструменты

Включённая группа содержит шесть команд:

| Инструмент | Назначение |
|---|---|
| `syntx_owner_get_wan25_i2v_preview_parameters` | Возвращает поддерживаемые локальные параметры и сведения о закреплённой C396-строке. |
| `syntx_owner_upload_wan25_i2v_preview_image` | Проверяет и загружает одно изображение, возвращая opaque handle вместо URL. |
| `syntx_owner_generate_wan25_i2v_preview_video` | Проверяет текущую связь, аккаунт и доступ, затем выполняет одну явную image-only попытку. |
| `syntx_owner_reconcile_wan25_i2v_preview_video` | GET-only проверка результата после неизвестного ответа на запуск. |
| `syntx_owner_list_wan25_i2v_preview_recoveries` | Показывает ограниченные сводки сохранённых в процессе попыток. |
| `syntx_owner_get_wan25_i2v_preview_result_page` | Читает страницу уже связанного результата. |

Для входа используются общие owner-команды `syntx_begin_login` и `syntx_check_login`. Завершите обычную авторизацию в том же owner-контуре, затем передавайте только выданный MCP `link_attempt_id` и opaque image handle.

## Входы и ограничения

- Поддерживается только `wan_25_i2v_preview`; WAN26, Flash и другие model IDs сюда не относятся.
- За одну попытку принимается одно локально проверенное изображение: JPG/JPEG, PNG, BMP или WebP. Текущие локальные проверки ограничивают файл 10 MiB и каждую сторону диапазоном 384–5000 пикселей. Это защитные проверки локального кода, а не подтверждённые пределы провайдера; строгого pixel-decoder acceptance эта интеграция не заявляет.
- Параметры должны быть указаны явно. Разрешение: `480P`, `720P`, `1080P`. Для `480P` доступны `16:9`, `9:16`, `1:1`; для `720P`/`1080P` также `4:3` и `3:4`. `video_duration` — только `5` или `10` секунд. `prompt_extend` задаётся явно, `seed` — `null` или целое от 0 до 2147483647.
- `native_audio` жёстко выключен, `shot_type` фиксирован в `single`, `audio_setting` — `auto`; вызвать или переопределить их нельзя. Хотя optional-audio ветка присутствует в preview UI, native-аудиовход в этой интеграции не реализован. Для image-only сценария `ffprobe` не требуется.
- Нельзя передать собственный URL, `file_urls`, путь к файлу, готовый settings object или аудио handle. Загрузка выполняется из переданных байтов в том же связанном контексте.
- До отправки сервис выполняет свежие account и model-access проверки для текущей связанной учётной записи. Неактивный аккаунт, недоступная модель или непригодная quote останавливают запуск до chat/generation POST. Quote не является enforceable spend cap: `cost_cap_enforced` остаётся `false`.

## Неизвестный результат и границы доказательств

Если ответ на generation POST неизвестен, повторный POST не выполняется автоматически. Используйте reconcile; он повторно читает состояние только GET-запросами. Recoveries хранятся в памяти текущего процесса и теряются при его перезапуске.

Наличие результата в истории и безопасная ссылка означают только локально наблюдённую доступность. `provider_terminal_status` и `backend_acceptance` остаются `UNPROVEN`; выдача URL не доказывает скачивание или декодирование видео. Закреплённая C396 snapshot — статический источник параметров; глобальный selector остаётся E551. Ни каталог, ни локальные synthetic tests не подтверждают текущую entitlement, тарификацию, фактические defaults UI или успешную работу провайдера.

Инструкция относится только к локальному owner-stdio пути. HTTP и другие transport/client hosts не проверены. Публикация в npm или исходный export — отдельные release-действия, здесь они не выполняются и этой страницей не обещаются. Проверяйте вывод инструментов перед любым платным действием.
